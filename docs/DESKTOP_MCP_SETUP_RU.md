# Настройка опционального локального desktop MCP (`hoi4_desktop`)

[简体中文](DESKTOP_MCP_SETUP.md) | [English](DESKTOP_MCP_SETUP_EN.md) | [日本語](DESKTOP_MCP_SETUP_JA.md) | Русский | [한국어](DESKTOP_MCP_SETUP_KO.md)

`hoi4_desktop` (`mcp-server/hoi4_desktop_mcp.py`) — это **стандартный универсальный локальный MCP-сервер** для **клиентов вне Codex**, у которых нет встроенного управления рабочим столом Windows (**Google Antigravity, Cursor, Claude Code, Gemini CLI, Windsurf, Cline** и др.). По умолчанию он отключён и включается только тогда, когда вы хотите поручить ИИ согласованное тестирование в игре по правилам [test-mod.md](../skills/hoi4-content-builder/workflows/test-mod.md).

Он **физически отделён** от сервера только для чтения `hoi4_local` (`mcp-server/hoi4_mcp.py`): повседневная разработка, аудит и статические проверки используют только `hoi4_local`, а `hoi4_desktop` можно отключить сразу после теста.

## Ключевые особенности и защита

- **Стандартный протокол, ноль зависимостей, ноль сети**: работает по стандартному MCP stdio JSON-RPC 2.0 исключительно на стандартной библиотеке Python 3, Windows Win32 API (`user32`/`gdi32`/`kernel32`/`shell32`) и чистом Python-кодировщике PNG — без `pip install` и сетевых портов.
- **Жёсткий белый список процессов**: сервер видит, снимает и управляет строго пятью процессами, связанными с HOI4; браузеры, мессенджеры, IDE и остальные окна полностью недоступны:
  - `hoi4.exe`
  - `paradox launcher.exe`, `dowser.exe`
  - `steam.exe`, `steamwebhelper.exe`
- **Захват только клиентской области и строгие границы координат**: снимается исключительно клиентская область проверенного окна (сначала `PrintWindow(PW_RENDERFULLCONTENT)`, при чёрном кадре DX11 — обрезанный строго по клиентскому прямоугольнику `BitBlt` только при подтверждённом фокусе); клики, перетаскивание и прокрутка идут в относительных координатах окна с отказом при выходе за границы.
- **Проверка фокуса и мгновенный стоп-кран**: перед каждым вводом заново проверяется принадлежность активного окна, запрещены `Alt+Tab` и `Alt+F4`, а перевод мыши в верхний левый угол экрана (`x <= 4, y <= 4`) мгновенно останавливает ввод.
- **Заточен под реальное тестирование HOI4**:
  - поддержка Per-Monitor V2 DPI и многомониторных виртуальных координат;
  - аппаратные скан-коды DirectX для горячих клавиш (консоль `` ` ``, `Space`, `Esc`);
  - ввод текста через `KEYEVENTF_UNICODE` (UTF-16) в обход раскладок и CJK IME, благодаря чему команды вроде `cp 100` или `pp 500` никогда не искажаются и не теряют пробелы;
  - самопроверка изолированного рабочего стола: `list_hoi4_windows` возвращает `desktop_name` и сразу предупреждает, если хост запустил сервер вне интерактивного рабочего стола `Default`;
  - запуск Steam жёстко ограничен URI `steam://rungameid/394360` с обязательным `confirm_user_authorized: true` и соблюдением правил авторизации и восстановления из `test-mod.md`.

## Требования

1. **Windows 10 / 11 и Python 3** (`py -3` или `python` в `PATH`).
2. **Рекомендуется режим «Без рамки» (Borderless) или «В окне» (Windowed)**: в эксклюзивном полноэкранном режиме часть драйверов блокирует захват GDI/`PrintWindow`.
3. **Одинаковый уровень прав**: запускайте `hoi4.exe` от обычного пользователя (без прав администратора), чтобы клиент с обычными правами мог отправлять события `SendInput`.

## Инструменты (10)

| Инструмент | Тип | Назначение |
| --- | --- | --- |
| `list_hoi4_windows` | Только чтение | Список видимых окон из белого списка (handle, процесс, заголовок, размеры клиентской области, фокус, имя рабочего стола) |
| `capture_hoi4_window` | Только чтение | Снимок только клиентской области целевого окна в PNG с метаданными координат, путём к временному файлу и встроенным MCP-изображением |
| `focus_hoi4_window` | Интерактивный | Разворачивает (если свёрнуто) и выводит на передний план проверенное окно |
| `click_hoi4_window` | Интерактивный | Клик внутри окна по нормализованным (`0.0–1.0`), клиентским или пиксельным координатам снимка (опционально со скриншотом после клика) |
| `drag_hoi4_window` | Интерактивный | Плавное перетаскивание внутри окна (прокрутка карты, ползунки, перетаскиваемые панели) |
| `scroll_hoi4_window` | Интерактивный | Прокрутка колёсика мыши в указанной точке (масштаб карты, списки решений и фокусов) |
| `send_hoi4_keys` | Интерактивный | Отправка клавиш и сочетаний аппаратными скан-кодами DirectX (`Alt+Tab` и `Alt+F4` заблокированы) |
| `type_hoi4_text` | Интерактивный | Ввод короткого текста (до 500 символов) напрямую через Unicode в обход IME |
| `run_hoi4_console_command` | Интерактивный | **Только `hoi4.exe`**: открывает консоль (`` ` ``), выполняет однострочную команду и опционально закрывает консоль со скриншотом |
| `launch_hoi4_steam` | Интерактивный | Открывает `steam://rungameid/394360` после явного согласия пользователя (`confirm_user_authorized: true`) |

## Примеры подключения

Замените `<REPO_ROOT>` на абсолютный локальный путь к этому репозиторию (или плагину). Держите сервер выключенным в обычной работе и включайте на время живых проверок.

### 1. Google Antigravity (рекомендуется как отдельный отключаемый плагин)

Разместите `plugin.json`, `mcp_config.json` и `mcp-server/hoi4_desktop_mcp.py` в `~/.gemini/config/plugins/hoi4-desktop-control/`, прописав в `mcp_config.json`:

```json
{
  "mcpServers": {
    "hoi4_desktop": {
      "command": "py",
      "args": [
        "-3",
        "-u",
        "C:\\Users\\<YOUR_USER>\\.gemini\\config\\plugins\\hoi4-desktop-control\\mcp-server\\hoi4_desktop_mcp.py"
      ],
      "cwd": "C:\\Users\\<YOUR_USER>\\.gemini\\config\\plugins\\hoi4-desktop-control"
    }
  }
}
```

После настройки плагин можно включать и выключать одним кликом в **Plugins Manager**, не затрагивая `hoi4_local` и три навыка.

### 2. Cursor / Claude Code / Gemini CLI / Windsurf / Cline

Добавьте блок в `mcpServers` вашего клиента (`.cursor/mcp.json`, `.mcp.json`, `~/.claude.json` или `~/.gemini/settings.json`):

```json
{
  "mcpServers": {
    "hoi4_desktop": {
      "command": "cmd.exe",
      "args": [
        "/d",
        "/s",
        "/c",
        "call",
        "<REPO_ROOT>\\mcp-server\\launch_desktop.cmd"
      ]
    }
  }
}
```

Также можно скопировать готовый шаблон [mcp-server/hoi4_desktop.mcp.example.json](../mcp-server/hoi4_desktop.mcp.example.json).

### 3. Codex

Настольный Codex уже имеет встроенное управление рабочим столом, поэтому `.mcp.json` по умолчанию подключает только `hoi4_local`.

## Автономная самопроверка (без воздействия на рабочий стол)

Запустите из корня репозитория:

```powershell
python scripts/test-desktop-mcp-server.py
```

Тест проверяет отклонение процессов вне белого списка, блокировку координат вне границ, кодирование/декодирование PNG, обработку `null`-аргументов, рукопожатие JSON-RPC, все 10 инструментов и отказ `launch_hoi4_steam` без разрешения — не запуская Steam и не трогая окна.
