# HOI4 AI Modding Skills — Руководство по установке и распространению

## Состав пакета

Этот комплект **ориентирован в первую очередь на сопровождение, диагностику, рефакторинг и развитие существующих модов *Hearts of Iron IV***, при этом полностью сохраняя сквозной процесс **создания нового контента и целых модов с нуля на обычном языке**. В него входят три тесно связанных Agent Skills:

- **`hoi4-review-debug`**: разбор журналов, межфайловый аудит, миграция версий, оптимизация производительности и тестирование в игре с вашего согласия;
- **`hoi4-pdx-modding`**: синтаксис PDX, структура каталогов, сверка с целевой сборкой игры и статическая проверка;
- **`hoi4-content-builder`**: воплощение игровых идей на обычном языке в готовые функции или целые моды со связанными скриптами, ресурсами, UI и многоязычной локализацией.

**Всегда устанавливайте все три навыка вместе.** Они ссылаются на общие правила, шаблоны и процедуры передачи работы, образуя единый контур «замысел → реализация → проверка». Можно описывать механики, правила и визуал сразу обычными словами, без предварительного написания PDX-кода; специфичные для конкретного мода переменные, флаги, зависимости и правила кодировки храните в его собственном техническом руководстве, чтобы общие навыки оставались лёгкими и переносимыми.

## Распространение и выпуск релизов

1. **Публикуйте исходный код и версионированные релизы** вместо безымянных архивов без истории.
2. **Делайте единый архив со всеми тремя навыками основным файлом релиза**, указывая версию, исходный коммит и размер архива (контрольные суммы добавляйте по требованию площадки или при проверке целостности передачи). Для платформ, принимающих навыки по одному, прикладывайте три отдельных ZIP из того же релиза с напоминанием установить все три.
3. **Сохраняйте метаданные и структуру**: включайте `LICENSE`, `ATTRIBUTION.md` и полное дерево каталогов каждого навыка.
4. **Соблюдайте границы прав на ресурсы**: никогда не добавляйте в релиз файлы базовой игры Paradox, материалы Workshop, ассеты сторонних модов или личные локальные пути. Файлы игры и зависимостей используются только локально для проверки.
5. **Актуализируйте под крупные патчи**: после каждого крупного обновления HOI4 перепроверяйте эталонные примеры базовой игры в `references/template-catalog.md` и указывайте проверенную сборку в описании релиза.

## Установка в разных клиентах

### ChatGPT

В учётной записи ChatGPT с поддержкой Personal Skills откройте меню профиля → **Skills** → **Create** → **Upload from your computer**, загрузите по очереди три ZIP-архива из одного релиза и убедитесь, что все три включены. На странице Skills ими можно поделиться с участниками рабочего пространства или создать ссылку. Доступность по тарифам и настройки администраторов описаны в [официальной справке OpenAI по Skills](https://help.openai.com/en/articles/20001066-skills-in-chatgpt); перед использованием сторонних пакетов проверяйте их происхождение и скрипты самостоятельно.

### Codex

- **Для текущего пользователя**: скопируйте три каталога навыков в `$CODEX_HOME/skills/`.
- **На уровне проекта**: скопируйте их в `<MOD_ROOT>/.agents/skills/` и храните в Git вместе с модом, сохраняя структуру:

```text
.agents/skills/
  hoi4-content-builder/SKILL.md
  hoi4-pdx-modding/SKILL.md
  hoi4-review-debug/SKILL.md
```

Обновите список или откройте новую задачу и формулируйте запросы по HOI4 обычным языком. Долгосрочные правила конкретного проекта и ссылки на его документацию держите в корневом `AGENTS.md`.

#### Дополнительно: установка Codex Plugin с локальными инструментами чтения

Корень репозитория сам служит источником Codex Plugin, объединяющим три навыка и локальный MCP-сервер только для чтения `hoi4_local` — удобный вариант для поиска установки HOI4, трассировки идентификаторов, проверки изменений Git, чтения журналов и метаданных медиа. Команды установки и правила безопасности описаны в [«Локальный плагин и помощник MCP»](LOCAL_MCP_PLUGIN_RU.md).

> **Важно**: после локальной установки или обновления плагина **откройте новую задачу Codex**. Уже запущенные сессии фиксируют список инструментов на старте, поэтому обновлённые навыки и MCP подхватываются именно в новой задаче.

### Cursor

Cursor Agent автоматически находит навыки проекта в `.agents/skills/<skill-name>/` или `.cursor/skills/<skill-name>/`, а пользовательские — в `~/.agents/skills/<skill-name>/` или `~/.cursor/skills/<skill-name>/`. Скопируйте все три каталога из одного релиза в выбранное место: проектный каталог удобно вести вместе с модом в Git, пользовательский — переиспользовать между проектами.

Переоткройте или обновите Agent: Cursor сможет подбирать навыки автоматически, а через `/` в чате их можно вызвать по имени. Навыки передаются любой выбранной модели; для работы личных `~/.cursor/skills/` в Cloud Agents включите синхронизацию Skills в настройках Cursor. При необходимости локального сбора данных или согласованного тестирования в игре подключите `hoi4_local` или `hoi4_desktop` в `.cursor/mcp.json`. Актуальные пути и правила см. в [официальной документации Cursor Agent Skills](https://cursor.com/docs/skills).

### Claude Code / claude.ai

- **Claude Code**: скопируйте три каталога в `~/.claude/skills/<skill-name>/` (для пользователя) или `.claude/skills/<skill-name>/` (в проект). Claude автоматически подгружает подходящий навык по `description` и поддерживает явный вызов. См. [документацию Claude Code Skills](https://code.claude.com/docs/en/slash-commands).
- **claude.ai**: загрузите ZIP-архивы пользовательских навыков в **Settings → Features**; правила тарифов, выполнения кода и API/workspace указаны в [обзоре Anthropic Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview).

### Gemini CLI / Google Antigravity

- **Gemini CLI**: обнаруживает пользовательские навыки в `~/.gemini/skills/` или `~/.agents/skills/`, а навыки рабочей области — в `.gemini/skills/` или `.agents/skills/`. После копирования выполните `/skills reload`; также доступны `/skills link <path> --scope user|workspace` и `gemini skills install <repository-url>`. См. [документацию Gemini CLI Skills](https://geminicli.com/docs/cli/using-agent-skills/).
- **Google Antigravity**: объедините три навыка и `mcp-server/hoi4_mcp.py` в локальный плагин только для чтения в `~/.gemini/config/plugins/`. Если требуется помощь ИИ с тестированием в игре в клиентах без встроенного управления рабочим столом (Antigravity, Cursor, Claude Code, Gemini CLI), включайте по запросу отдельный сервер с белым списком процессов `hoi4_desktop` — см. [«Настройка локального desktop MCP»](DESKTOP_MCP_SETUP_RU.md).
