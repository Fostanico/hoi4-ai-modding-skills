# Локальный плагин HOI4 и помощник MCP только для чтения (`hoi4_local`)

[简体中文](LOCAL_MCP_PLUGIN.md) | [English](LOCAL_MCP_PLUGIN_EN.md) | [日本語](LOCAL_MCP_PLUGIN_JA.md) | Русский | [한국어](LOCAL_MCP_PLUGIN_KO.md)

## Архитектура и назначение

Плагин объединяет **три Agent Skills** и **локальный MCP-сервер только для чтения (`hoi4_local`)**:
- **Навыки** задают методологию: проектирование механик, проверку по целевой версии, оценку доказательств, границы правок и аккуратную передачу работы.
- **`hoi4_local` MCP** ускоряет локальный сбор фактов, предоставляя частые операции чтения как структурированные ограниченные инструменты.
- **Манифест Codex Plugin** упаковывает оба компонента в один модуль для синхронной установки и обновления.

Задача `hoi4_local` — быстро и точно подавать локальные факты; итоговые выводы о синтаксисе и работе в игре строятся по примерам целевой сборки, включённым зависимостям и наблюдениям в игре. В клиентах без MCP полный рабочий процесс также доступен через скрипты PowerShell, Python, `rg` и Git из репозитория.

## Шесть инструментов только для чтения

| Инструмент | Что делает | Практические советы |
| --- | --- | --- |
| `detect_hoi4_environment` | Находит рабочие каталоги модов, установку HOI4, пользовательские данные, журналы и Workshop | Даёт карту локальных путей; список активных модов уточняйте по плейсету или `dlc_load.json` |
| `trace_hoi4_identifier` | Ищет ID, флаги, ключи локализации и имена GFX в моде, базовой игре и указанных зависимостях | Возвращает точные совпадения в тексте; далее проверьте, действительно ли вызывающий код их использует |
| `validate_hoi4_changes` | Запускает лёгкую статическую проверку PDX и локализации для указанных путей или изменений Git | Проверяет только затронутые файлы без права записи; для полного аудита используйте Mod Doctor |
| `read_hoi4_logs` | Читает ограниченный хвост `error.log`, `game.log` и других зарегистрированных логов HOI4, схлопывая повторы | Оставляет журналы нетронутыми; перед разбором сверьте время файла с последним запуском |
| `inspect_hoi4_media` | Читает размеры и метаданные DDS/PNG/JPEG/GIF, а при наличии `ffprobe` — аудио- и видеопотоки | Сообщает объективные параметры файла; требования к рендерингу сверяйте с конкретным элементом GUI/GFX |
| `lookup_hoi4_console_commands` | Ищет по всем 458 консольным командам и переменным HOI4 1.20.0 по имени, псевдониму, категории или смыслу (с авто-подгрузкой `documentation/console_commands_documentation.md`) | Показывает доступность в релизной сборке, влияние на ИИ, типовые ловушки (`eval_effect` вместо `effect`) и предупреждения о dev-only командах |

Все шесть инструментов **строго только для чтения**: они не запускают Steam или HOI4, не меняют плейсеты, не редактируют и не удаляют файлы модов и не вмешиваются в процессы игры. Для захвата окна и ввода при тестировании в игре используйте полностью отдельный опциональный сервер `hoi4_desktop` ниже.

## Модель запуска и транспорта

- **Локальный stdio-транспорт**: клиент запускает дочерний процесс по требованию и обменивается строчными сообщениями UTF-8 JSON-RPC через stdin/stdout. Жизненный цикл процесса управляется клиентом, сетевые порты не открываются.
- **Ноль зависимостей и ноль сети**: работает исключительно на стандартной библиотеке Python 3, не требует облачной базы HOI4 или ключа OpenAI API. Если в `PATH` есть `ffprobe`, медиаинструмент автоматически добавит сведения о потоках; при отсутствии просто сообщит об этом, ничего не скачивая.

## Установка и обновление

Корень репозитория сам служит источником плагина: `.codex-plugin/plugin.json` указывает на единый каталог `skills/` и `.mcp.json`. Проверки для разработчиков:

```powershell
python scripts/test-mcp-server.py
python <plugin-creator>/scripts/validate_plugin.py <repository-root>
```

В Windows достаточно выполнить из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-codex-plugin.ps1
```

Скрипт поддерживает отдельный локальный marketplace `hoi4-local-modding` в каталоге данных текущего пользователя, добавляет метку обновления и регистрирует плагин через Codex CLI без ручного редактирования JSON. После установки или обновления **откройте новую задачу Codex**, чтобы загрузить свежие навыки и инструменты. В релизах публикуются и общий ZIP плагина, и три отдельных ZIP-архива навыков для остальных клиентов.

## Границы безопасности и устранение неполадок

- **Чистый канал stdio**: в stdout попадает ровно одно сообщение UTF-8 JSON-RPC на строку; диагностика уходит в stderr.
- **Ограниченный поиск**: сканируются только разрешённые текстовые расширения с пропуском `.git`, `node_modules` и `dist` и лимитами на размер файла и число совпадений.
- **Изоляция рабочей области**: проверка и анализ медиафайлов строго ограничены переданным `mod_root`, с блокировкой выхода через `..` и ограничением числа файлов за вызов.
- **Белый список логов**: `read_hoi4_logs` читает только заранее зарегистрированные имена журналов HOI4.
- **Если инструменты MCP не появились**: убедитесь, что `python` или `py -3` есть в `PATH`, откройте новую задачу и проверьте сервер командой `python scripts/test-mcp-server.py`.

## Опциональное дополнение: отдельный desktop MCP для живых тестов (`hoi4_desktop`)

Чтобы `hoi4_local` всегда оставался строго только для чтения, все функции скриншотов и ввода с мыши/клавиатуры вынесены в отдельный, **отключённый по умолчанию** локальный сервер `mcp-server/hoi4_desktop_mcp.py` (`hoi4_desktop`):

- предназначен для клиентов без встроенного управления рабочим столом Windows (**Google Antigravity, Cursor, Claude Code, Gemini CLI** и др.);
- чистая стандартная библиотека Python 3 + Win32 API, без сторонних пакетов и сетевых сокетов;
- жёсткий белый список процессов ограничен `hoi4.exe`, `Paradox Launcher`, `dowser.exe` и `Steam` — браузеры, мессенджеры и IDE полностью недоступны;
- соблюдает все правила авторизации, бюджета короткого теста и восстановления настроек из `hoi4-content-builder/workflows/test-mod.md`.

Примеры конфигурации, детали безопасности и автономная самопроверка (`python scripts/test-desktop-mcp-server.py`) описаны в [«Настройка локального desktop MCP»](DESKTOP_MCP_SETUP_RU.md).

В дальнейших планах — разбор активного плейсета, граф порядка загрузки descriptor и более точная атрибуция причин в логах.
