## 更新内容

本版更新至《钢铁雄心 IV》Operation Postern **1.20.0.0.8873（0c4f）** 的原版资料基线，对应 Steam 2026 年 11 月 19 日的 To the Bitter End 更新。[Paradox 官方补丁说明](https://steamcommunity.com/games/394360/announcements/detail/684145170657051627)

- 新增 `any_war_participation` 用法，说明国家作用域、0–1 阈值，以及同时参战时的匹配范围。补充 `division_has_battalion_in_template` 修正后的迁移检查。
- 增加罗马尼亚新旧国策树、国际合作决议与界面、角色、军工机构和东线历史/AI 覆盖的迁移检查点。
- 更新原版文档索引，补上核心州集合过滤、陆军总部部署值和 `start_border_war` 的属国参战选项。
- 收录 v1.8.0 之后已合入的通用开发指南、日语/俄语/韩语 README 与韩语本地化模板。

附件包含完整源码与 Codex 插件包，以及三个独立 Skill ZIP。使用独立 ZIP 时，请安装同一版本的三套技能。此次核对了官方补丁说明和本机原版文件，并运行仓库静态回归。未启动游戏。各模板保留原有核验版本。

## What's changed

This release updates the installed-source baseline to **HOI4 Operation Postern 1.20.0.0.8873 (0c4f)**, the 19 November 2026 To the Bitter End update. [Paradox patch notes](https://steamcommunity.com/games/394360/announcements/detail/684145170657051627)

- Document the country-scoped `any_war_participation` trigger, its 0–1 threshold and its matching behavior across multiple wars. Add a migration check for the `division_has_battalion_in_template` fix.
- Map Romanian focus trees, International Cooperation decisions and GUI, characters and MIOs, and Eastern Front history and AI overrides.
- Refresh the vanilla documentation index with core-state collection filters, Army HQ deployment values, and the subject participation option for `start_border_war`.
- Include the general modding guides, Japanese/Russian/Korean READMEs, and Korean localisation templates merged since v1.8.0.

Download the complete source and Codex plugin archive, or install all three individual skill ZIPs from the same release. Verification covered the official notes, installed vanilla files, and the repository's static regression suite. HOI4 was not launched. Individual templates retain their recorded verification builds.
