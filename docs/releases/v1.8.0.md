## 更新内容

汇总 v1.7.0 以来的更新，原版资料基线更新至 HOI4 1.19.4（a783）。

- 根据官方更新日志与本地文件补充燃油 AI 阈值、装备属性缩放、引擎修正和 GUI 覆盖迁移点；缺少完整本地证据的参数继续明确标为待核实。
- 三套技能共用验证、证据复用、预算、停工与交接规则。局部修复只复验受影响部分，文档按实际合同变化更新。
- 短测优先复用播放集、只启用所需 Mod，并使用控制台快速准备；按问题选择当前会话、存档或新局，准备与清理计入时间预算。
- GPT 系列保留实机测试必要性判断；用户拒绝测试时简短交接，详细手测清单按需提供。
- 普通文件不再默认计算哈希，查重和内容比较保留显式开关；修复对应 CI 夹具调用，发布校验和也改为按需提供。
- 新增 GUI shader 外层格式检查器及失败负例，接入静态 CI；明确独立 HLSL 编译无法证明游戏外层解析成功。

提供完整源码／插件包和三个单独 skill ZIP。请安装同一版本的全部三个技能，保留兄弟目录关系。

本次发布不启动 HOI4。1.19.4 资料更新不代表所有模板与 Mod 功能均已通过该版本实机验收；历史验收保留原版本与场景边界。

## What's changed

Changes since v1.7.0, with the installed-source reference baseline updated to HOI4 1.19.4 (a783).

- Refresh fuel AI thresholds, equipment stat scaling, engine fixes, and GUI migration targets against official notes and installed files; retain explicit gaps where local evidence is incomplete.
- Share evidence, validation, budget, stop, and handoff rules across all three skills. Recheck affected paths after local fixes and update documentation when its contract changes.
- Reuse existing playsets and console shortcuts for short tests. Choose a relevant session, save, or new game, counting preparation and cleanup in the time budget.
- Retain the GPT-specific native-test necessity gate; keep declined-test handoffs concise and provide detailed manual steps on request.
- Make routine hashing optional, preserve explicit duplicate/content comparison, and fix the CI fixture callers. Release checksums are also optional.
- Add a GUI shader wrapper checker with known-bad regression cases to static CI; standalone HLSL compilation does not prove native wrapper parsing.

The complete source/plugin archive and three individual skill ZIPs are included. Install all three skills from the same version as sibling directories.

No HOI4 session was launched for this release. The 1.19.4 source refresh does not certify every template or mod feature at runtime; earlier runtime evidence remains tied to its original build and scenario.
